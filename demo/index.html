What it fixes

Common complaints about chart libraries, and what MiniChart does instead.

The library is bigger than the rest of my page.
About 8 KB gzipped, with no dependencies.
Zoom needs a plugin.
Zoom, pan and pinch are built in.
Scrolling the page gets stuck on charts.
The wheel only zooms with Ctrl/⌘ or after you click the chart.
Large datasets freeze the page.
100,000 points draw in about one frame.
Tooltips show one series at a time.
Every series at that point, by default.
Canvas charts are invisible to screen readers.
A spoken summary, a hidden data table and arrow-key navigation that reads each value.
Dark mode needs its own config.
Colours follow your page's text colour.
Arabic charts read the wrong way.
Right-to-left pages get a mirrored time axis and the value axis on the right.

Use it

<div id="chart"></div>
<script src="minichart.js"></script>
<script>
  const chart = MiniChart('#chart', {
    type: 'line',            // 'line', 'area' or 'bar'
    title: 'Visitors',
    labels: ['Jan', 'Feb', 'Mar'],
    series: [{ name: 'Visits', data: [120, 340, 280] }],
  });
  chart.update({ series: [{ name: 'Visits', data: [130, 310, 400] }] });
</script>
